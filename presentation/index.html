Protecting Crankshaft Precision Machining

DOMAIN GROUNDING
⚙️ Precision Machining Risk Profile
  • Component Criticality: Crankshaft Main Journals require strict Ø50 mm h5 (-0.011 mm) clearance fit with bearings.
  • Finish Turning: Operating at 600–900 RPM using CBN tools generates high thermal friction at spindle bearings.
  • Thermal Runaway: Unmonitored spindle bearing heat leads to thermal distortion (>12 µm runout), causing scrapped engine assemblies.
  • Coolant Failure: Flood coolant (5–8 bar) failure causes temperature spikes past 80°C in under 15 seconds.
🛡️ ROS 2 Cyber-Physical Solution
  • Real-Time 10 Hz Telemetry: Micro-second stamped sensor streaming over /machine/temperature.
  • EMA Vibration Filtering: Exponential low-pass filter eliminates machining tool chatter spikes.
  • Dual-Threshold Hysteresis: Alarm triggers at ≥80°C; holds state until temperature safely clears below 75°C.
  • Watchdog Sensor Guard: Automatic detection of thermocouple wire break within 1.0 s (STALE detection).

SIGNAL PROCESSING
📐 Mathematical Formulation

At each discrete time sample $k$ (where $\Delta t = 0.1\text{ s}$):

y[k] = α · x[k] + (1 - α) · y[k-1]
  • $x[k]$: Raw sampled temperature from spindle sensor
  • $y[k]$: Filtered output evaluated by hysteresis logic
  • $\alpha$: Smoothing factor $\alpha \in (0, 1]$

Configurable Behavior:

  • α = 0.2 (Default): Attenuates mechanical vibration noise & chatter while tracking thermal inertia.
  • α = 1.0 (Testing): Direct pass-through for deterministic threshold validation.

CONTROL & SAFETY
🔁 Hysteresis State Transition Logic
High Limit: 80.0 °C | Low Limit: 75.0 °C
  • Rising Edge (T ≥ 80.0°C): Alarm → True, Status → ALARM. CNC spindle emergency halt triggered.
  • Hysteresis Deadband (75.0°C ≤ T < 80.0°C): State holds previous value. Prevents oscillation due to thermal fluctuations near threshold.
  • Cooling Edge (T < 75.0°C): Safe operating envelope restored. Alarm → False, Status → NORMAL.

RELIABILITY
⏱️ Watchdog Execution Pipeline
  • Periodic Inspection: Timer evaluates arrival gap at 10 Hz (0.1 s).
  • Monotonic Clock Calculation: elapsed = (now() - last_received).nanoseconds / 1e9
  • Threshold Transition: If elapsed > stale_timeout (1.0 s):
    • System status immediately transitions to STALE.
    • Warning message dispatched to ROS 2 logger.
    • All reset requests locked out.
  • Seamless Restoration: Once fresh 10 Hz sensor packets arrive, the monitor resumes normal evaluation.
