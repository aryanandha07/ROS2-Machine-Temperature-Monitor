⚠️ The Industrial Problem

Machine Overheating Risks: Abnormal machine and spindle temperatures cause catastrophic equipment damage, geometric machining inaccuracies, and costly production downtime.

  • Spindle Thermal Expansion: Bearing friction induces runout errors exceeding micrometric tolerances.
  • Sudden Coolant Failure: Loss of coolant flow drives temperatures past 80°C in seconds.
  • Sensor Blinding: Broken wires cause controllers to act on frozen, false-safe data.
🎯 The ROS 2 Cyber-Physical Solution
  • MONITOR: Real-time streaming of calibrated temperature data at 10 Hz via ROS 2.
  • FILTER: Exponential Moving Average (EMA) to attenuate mechanical chatter spikes.
  • ALARM: Dual-threshold hysteresis activating at 80°C and clearing safely below 75°C.
  • SAFETY: Monotonic heartbeat watchdog detecting stale data (>1.0s) and providing an interlocked safe reset service.
  • SCOPE: Verified software prototype ready for physical smart manufacturing integration.

🧠 NODE 02: Temperature Monitoring Node

Primary Function: EMA filtering · threshold comparison · timeout detection · diagnostics.

Configurable Parameters:

  • high: 80.0 °C • low: 75.0 °C
  • alpha: 0.2 default • stale_timeout: 1.0 second

ROS 2 Outputs & Services:

  • /machine/alarm (std_msgs/msg/Bool)
  • /machine/status (std_msgs/msg/String)
  • /machine/reset (std_srvs/srv/Trigger)
  • /diagnostics (diagnostic_msgs/msg/DiagnosticArray)

🔁 Threshold & Hysteresis Zone
  • 80°C HIGH: At or above 80°C, activate the alarm (alarm = True, status = ALARM).
  • HYSTERESIS ZONE: Between 75°C and 80°C, hold the existing state. Prevents relay chatter.
  • 75°C LOW: Below 75°C, clear the alarm (status = NORMAL).
  • SAFE RESET: Reject reset when temperature is unsafe (≥75°C) or data is stale.
📐 Filter Equation
FilteredTemperature = α × CurrentReading + (1 − α) × PreviousFilteredTemperature

α = 0.2: Balances the latest reading against historical values to attenuate machining noise.
α = 1.0: Pure pass-through for exact deterministic evaluation.

🖥️ Interactive Operator Desktop GUI

Implemented in machine_dashboard.py using Tkinter:

  • Dual Readouts: Real-time display of Raw vs. Filtered temperature.
  • Status Annunciator: Green (NORMAL), Red Flashing (ALARM), Amber (STALE).

🧊 3D RViz Digital Twin Marker

Implemented in rviz_marker_publisher.py:

  • Renders a 3D cylindrical model of the machine spindle in RViz2.
  • Thermal Heatmapping:
    • Green ($<75^\circ\text{C}$): Safe normal operation.
    • Amber ($75^\circ\text{C} - 80^\circ\text{C}$): Warning deadband.
    • Pulsing Red ($\ge 80^\circ\text{C}$): Active Overheat Alarm.
    • Translucent Gray: STALE sensor failure.
